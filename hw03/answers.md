df vs du: почему не совпадают
df -Th / — суперблок
Читает метаданные ФС: общий / занятый / свободный. Мгновенно.

Filesystem Type Size  Used Avail Use%
/dev/sdc   ext4 1007G  15G  941G   2%
du -sh /* — обход дерева
Рекурсивно считает размеры файлов. Медленно.

sudo du -sh /* 2>/dev/null \
  | sort -rh | head -10
3 причины расхождения
#	Причина	Суть
1	Deleted-but-open files	Файл удалён, но процесс держит fd → df считает, du не видит
2	Reserved blocks	ext4 резервирует 5% для root → df вычитает
3	Sparse files	du = реальные блоки, du --apparent-size = логический размер
