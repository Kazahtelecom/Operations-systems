# Linux FS AI Agent (Telegram Bot)

Финальный проект по курсу «Операционные системы» (Май 2026).  
Разработан студентом группы ПИ-21-1 Куандыковым Жасуланом.

Проект представляет собой интеллектуального ИИ-агента в мессенджере Telegram, способного диагностировать операционную систему Linux (WSL2 / Ubuntu), анализировать состояние файловой системы, утилизацию дисков и метрики запущенных процессов, используя возможности **Function Calling** модели `gemini-2.5-flash`.

## 🚀 Ключевые особенности и архитектура

1. **Официальный Google GenAI SDK (v2.0+)**: Архитектура построена на базе актуальной библиотеки `google-genai`, используя класс `genai.Client`.
2. **Native Automatic Function Calling**: Реализован продвинутый цикл выполнения (Agent Loop), делегированный на сторону SDK через конфигурацию `types.AutomaticFunctionCallingConfig(disable=False)`. Модель сама определяет необходимость вызова утилит, локально исполняет код и агрегирует финальный текстовый ответ.
3. **Асинхронный Telegram Engine**: Бот функционирует на базе асинхронной библиотеки `python-telegram-bot` (v20+), обеспечивая стабильный конкурентный пулинг (`run_polling`).
4. **Безопасность (Security First)**: В коде полностью отсутствует хардкод токенов или API-ключей. Конфиденциальные данные подтягиваются исключительно из переменных окружения операционной системы.

## 🛠 Реализованные инструменты (9 Tools)

Бот успешно перевыполняет базовые требования спецификации (минимум 7 инструментов) и включает в себя:

### Базовые инструменты файловой системы:
* `find_files` — Поиск файлов по рекурсивной маске с использованием безопасного встроенного модуля `glob`.
* `read_file` — Безопасное чтение текстового содержимого файлов (с ограничением до 2000 символов во избежание переполнения контекста).
* `file_info` — Извлечение низкоуровневых метаданных файла (размер, inode) средствами системных вызовов `os.stat`.
* `create_file` — Создание или перезапись текстовых файлов на FS.
* `disk_usage` — Высокоуровневый мониторинг дискового пространства (вычисление Total/Free GB через `os.statvfs`).

### Системные и инфраструктурные инструменты:
* `get_time` — Возвращает текущее системное время сервера.
* `system_info` — Сбор информации о ядре ОС (`uname -a`) и сетевом имени хоста.
* `process_list` — **[Системный Tool]** Получение топ-5 процессов, наиболее активно утилизирующих ресурсы CPU, в режиме реального времени.

### Расширенные инструменты:
* `find_large_files` — **[Расширенный Tool]** Поиск тяжелых файлов (по умолчанию >10МБ) в указанной директории с отсечением через `head` для предотвращения перегрузки буфера.
